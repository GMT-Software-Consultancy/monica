# Test feature: PM answer sheet (the "oracle")

*Exploratory draft · 29 Sep 2026 · used for an exploratory document run before the scope
discussion. Not frozen for the main round.*

Whoever answers the agent's questions at a gate (a person or a stand-in agent) uses **only**
this sheet. Log every question asked and the answer given.

**Rule for anything not on this sheet:** reply exactly:

> No strong view. Use your judgement and write the assumption down.

This sheet is deliberately thin. Scope, format and privacy questions fall through to the
rule above, so each run shows what the agent decides on its own.

---

| If asked about… | Answer |
|---|---|
| Who the users are | People who keep their relationship data in Monica, including self-hosters. Some want a personal backup; some want to reuse the data in other tools |
| Why they want it | They want a copy of what they've recorded about a person that they control, outside Monica |
| Where the option goes | On the contact's page |
| More than one contact at once | No, one contact |
| Importing the file back | No, export only |
| Designs or mock-ups | None |
| Success metrics or tracking | Out of scope for this test. Don't add tracking |
| Paid plans | Doesn't apply. Everyone gets it |
