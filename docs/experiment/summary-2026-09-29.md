# Summary: 29 Sep 2026

## What we did

- **Set up the test.** Wrote the stakeholder seeds, the pilot intent reference and the answer
  sheets, and tagged a base commit.
- **Built a harness.** It runs any arm in a clean sandbox with a pinned model (Opus 5.5) and
  a pinned Claude Code version. A stand-in PM answers from a fixed sheet. It saves questions,
  outputs, tokens, time and cost, with blind run IDs.
- **Ran 12 document-stage runs**, taking the seed to a spec and tickets, or to a plan:
  - pilot feature, 4 runs;
  - test feature with a thin answer sheet, 4 runs;
  - test feature with a realistic answer sheet, 4 runs.
- **Scored every run blind.** Pilot runs got an intent diff against the intent reference.
  Test-feature runs got a decision inventory: what the documents decided, and whether it was
  asked, flagged or decided silently.
- **Cost:** $19.77 API-equivalent for all 12 runs, about 5 minutes per run.

The code stage has not run yet. Garry is doing it.

## What we found

**Test feature, realistic answer sheet:**

| Arm | Silent decisions (never raised) | Consequential | False authority | Build details in spec |
|---|---|---|---|---|
| 0: Prompt + plan | 8 | 0 | 1 | n/a |
| A: No architecture | 8 | 2 | 0 | 0 |
| B: Architecture, no fence | 17 | 1 | 1 | 6 |
| C: Architecture, fenced | 8 | 1 | 0 | 0 |

1. **Part of the "silent decisions" came from the stand-in PM.** With a realistic answer
   sheet, silent decisions fell from 13–15 to 8 for arms A and C, but barely moved for arm 0
   and rose for arm B. (The scoring instructions also got tighter between the two rounds.)
   What remains was never raised with anyone: genuinely hidden. But only 0 to 2 per run matter. Examples: a
   "full copy" that silently drops the timeline, and other vault members' names leaving in
   the file.
2. **The fence works, three times over.** Without it, the spec fills with build details and,
   in this run, doubles the silent decisions (17 against 8). With it, the spec names no
   build details and stays at the level where a PM can review it.
3. **The fence has a cost on small features.** On the pilot, the fenced spec left the file's
   shape to engineering. Is that a gap or the right level? We need to decide.
4. **The prompt-only arm is a strong rival** on documents. It asks good questions and is
   cheapest. Its weak spot is judgement on scope: with the thin sheet, its "full copy" left
   out phone numbers and addresses.
5. **False authority is real.** The agent writes "the PM decided" for decisions the PM
   deferred or never saw. That gets past the human gate as approved.
6. **The skills don't force decisions to a person.** They surface what the agent *recognises*
   as a decision. Decisions buried in field lists and acceptance criteria pass through.
